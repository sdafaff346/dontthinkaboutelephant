# 🐘 코끼리를 생각하지마 (SillyTavern 확장)

> 코끼리는 잊지 않아요.

1000턴이 넘는 장기 채팅에서도 AI가 이야기를 잊지 않도록, 지난 대화를 **계층 요약 + 구조화된 기록부**로 압축해 프롬프트에 넣어주는 확장입니다.

## 어떻게 기억하나요

| 층 | 내용 |
|---|---|
| 작품 설정 | 오리지널 / 원작 유지 / AU / 자유 2차 창작, 원작 제목, 캐릭터 소개 |
| 전체 줄거리 | 오래된 챕터가 합쳐져 쌓이는 가장 압축된 기억 |
| 챕터 | 에피소드 여러 개를 합친 중간 요약 |
| 에피소드 | "압축" 한 번에 만들어지는 구간 요약 (중요도 1~5, 회상 키워드 포함) |
| 기록부 | 현재 상황 · 인물 · 관계 · 진행 중인 일/약속 · 사실/비밀 · 중요 물건 · 원작과 달라진 점 |
| 사건 | 요약할 때 따로 뽑는 개별 사건 (누가·어디서·무엇을·원인·결과·중요도). 압축되지 않고 계속 보관 |
| 보관함 | 압축으로 줄어든 옛 요약 원문 |
| 원본 메시지 | 요약되어 숨겨진 실제 대화. 지워지지 않고 검색 대상이 됨 |

- **덜 중요한 기억부터 압축**: 기억이 예산(토큰)을 넘으면 중요도 낮은 에피소드를 먼저 짧게 줄이고, 그다음 오래된 것을 챕터 → 전체 줄거리로 합칩니다. 중요도 4~5 내용은 최대한 보존하고, "고정"한 항목은 건드리지 않아요. 최신 에피소드 몇 개는 항상 보호됩니다.
- **기억 유지 강화**: 기억 본문은 캐릭터 설정 뒤에, 짧은 "현재 상태" 리마인더는 최근 대화 근처에 따로 넣습니다. 긴 컨텍스트에서 모델이 앞쪽 정보를 흘려버리는 걸 줄여줘요.
- **모델 호환**: JSON 스키마 같은 특정 API 기능에 의존하지 않고 태그 형식으로 주고받습니다. `<think>` 같은 추론 블록이나 코드펜스가 섞여 나와도 걸러내고, 해석에 실패하면 한 번 더 요청합니다. Gemini, GPT, Claude, GLM, DeepSeek, MiMo, Kimi 등 Chat/Text Completion 어느 쪽이든 사용 가능합니다.

## 회상 · 벡터 검색 (v1.1)

매 응답 직전에 최근 대화를 검색어로 삼아 **사건 · 보관함 · 요약된 원본 메시지**에서 지금 장면과 관련된 과거를 찾아, 최근 대화 바로 앞에 `<recalled_memories>`로 넣습니다.

1. **의미 검색**: SillyTavern 내장 벡터 저장소(`/api/vector`)로 뜻이 비슷한 장면을 찾습니다. ("배고파" → "점심 먹으러 가자")
2. **키워드 검색**: BM25 방식. 한국어·일본어·중국어는 두 글자 단위로 쪼개서 조사나 띄어쓰기 차이에도 잘 찾아요.
3. **결과 합치기**: 두 검색 순위를 RRF로 합친 뒤 **관련도 · 중요도 · 최근성** 가중치로 다시 정렬하고, 토큰 상한 안에서 골라 넣습니다.

벡터 검색이 실패하거나 꺼져 있어도 키워드 검색만으로 계속 동작합니다.

### 임베딩 소스 고르기
- 기본값은 **ST 벡터 저장소 설정 따르기**입니다. 확장 패널의 Vector Storage에서 고른 소스와 모델을 그대로 써요.
- 따로 지정하려면 패널의 "임베딩 소스"에서 고르세요. API 키는 ST의 API 연결 화면에 저장된 것을 사용하므로 이 확장에 키를 넣을 필요가 없습니다.
- 돈 안 드는 선택: **Local (Transformers)**. 다국어 정확도를 원하면 Ollama의 `bge-m3`, Gemini 임베딩, OpenAI `text-embedding-3-large` 등이 좋습니다.
- 임베딩 소스를 바꾸면 색인을 새로 만들어야 하니 **벡터 색인 맞추기**를 한 번 눌러주세요. (채팅을 열 때와 압축 후에는 자동으로 맞춰요)
- **검색 테스트** 버튼이나 `/lm-search 검색어 | /echo` 로 무엇이 회상되는지 미리 볼 수 있습니다.

## v1.9.40 QR 설명 문구 정리

설정과 QR 메시지 분류 창의 설명에 든 QR 예시를 일반적인 예시(퀴즈, 인터뷰, 만약에 시뮬레이션, 장면 넘기기)로 바꿨어요. 동작은 그대로예요.

## v1.9.39 상태창 기억

답변에 붙는 상태창을 요약과 따로 읽어서 기억해요. API는 쓰지 않아요. 지원하는 모양은 이래요.

- **한 줄 상태창:** `[ 🌙 오후 8:15 · 1943년 12월 9일 (목) · 호그와트 → 병동 · ❄️ 눈발, -1°C ]`처럼 `·`, `|`로 나뉜 줄이에요.
- **줄마다 이름표가 붙은 상태창:** "📅 날짜: … / ⏰ 시간: … / 📍 장소: … / 🌡 날씨: …" 형식이에요.

읽은 상태창은 세 군데에 써요.

- **가장 최근 상태창을 AI에게 알려줘요.** 요약으로 옛 답변이 숨겨지거나, 중간에 QR 번외편이 끼어도 시간·날짜·장소가 이어지게 리마인더에 넣어요. 리롤할 때는 지금 다시 쓰는 답변의 상태창을 빼고 그 앞의 것을 알려줘요.
- **에피소드의 작중 시간을 상태창으로 정해요.** 요약한 구간의 첫 상태창부터 마지막 상태창까지를 작중 시간으로 적어서 연표가 정확해져요.
- **상태창 기록:** 설정 → 요약 → 상태창의 '상태창 기록', 기억장 → 기록부, 또는 `/lm-status`로 열어요. 시간·장소·날씨가 바뀐 순서대로 보이고, 누르면 그 메시지로 가요. '지난 요약의 작중 시간 채우기'로 이미 만든 에피소드에도 상태창 시간을 넣을 수 있어요(되돌리기 가능).

설정 → 요약 → 상태창에서 끄거나 바꿀 수 있어요.

- **상태창 기억:** 자동으로 찾기 / 직접 정한 모양으로 찾기 / 쓰지 않기 중에서 골라요.
- **직접 정한 모양 (정규식):** 모양이 특이하면 '직접 정한 모양으로 찾기'를 고르고 정규식을 적어요. 괄호 ( )로 묶은 부분을 상태창 내용으로 읽어요.
- **마지막 상태창을 AI에게 알려주기**와 **작중 시간은 상태창 기준으로**는 따로 켜고 끌 수 있어요.

사용자 메시지와 QR 번외편에 붙은 상태창은 읽지 않아요.

## v1.9.38 답변 지울 때 알림 끄기

'현재 상태 실시간 갱신'을 켠 채로 답변을 지우거나 리롤하면 "지운 답변 때문에 바뀌었던 기록부 …건을 원래대로 돌려놨어요" 알림이 매번 뜨던 걸 없앴어요. 되돌리기는 그대로 하고, 기록은 활동 기록에만 남겨요.

답변이 실제로 바꾸지 않은 항목까지 되돌린 것으로 세던 것도 고쳤어요.

## v1.9.37 QR 번외편 자동 분류

롤플을 잠깐 멈추고 퀴즈, 인터뷰, 만약에 시뮬레이션 같은 걸 뽑는 QR을 **번외편**으로 알아보고 기억에서 빼요.

- **`/gen <System>Pause/STOP the role-play …</System> | /sendas` 형식:** 생성 지시문에 "롤플 멈춤(Pause/Stop/Halt … role-play·RP·scenario)" 문구가 있으면 번외편으로 표시해요. 요약, 회상 검색, 답변 점검에서 모두 빠져요.
- **`/send <System>…</System> | /trigger` 형식:** 같은 문구가 있는 유저 메시지와 그 뒤에 나온 답변을 함께 번외편으로 표시해요.
- **이야기를 이어 가는 QR**(장면 넘기기처럼 롤플 멈춤 문구가 없는 /gen + /sendas)은 그대로 이야기로 기억해요.
- **/comment 결과**(분석 QR 등)는 전처럼 빠져요.

설정 → 요약의 'QR·슬래시 명령 메시지' 기본값이 **'코멘트와 번외편만 빼기'**로 바뀌었어요.

**QR 메시지 분류:** 바로 아래 버튼을 누르면 슬래시 명령으로 들어온 메시지를 모아 보여줘요. 각 메시지를 번외편/이야기로 직접 고를 수 있어요. 이 버전 전에 생긴 메시지는 자동 표시가 없어서 '추정'으로 보이니, 한 번 열어서 확인하고 저장하세요. 이미 요약에 들어간 번외편은 해당 기억에 '다시 요약' 표시가 붙어요.

## v1.9.36 빠른 답장(QR) 메시지 빼기

빠른 답장(QR) 스크립트가 /comment, /sys, /sendas로 채팅에 넣는 분석·상태·선택지 메시지를 따로 알아봐요. 실리태번은 이런 메시지에 '슬래시 명령으로 넣음' 표시를 남기는데, 그걸 보고 골라내요.

설정 → 요약의 'QR·슬래시 명령 메시지'에서 고를 수 있어요.

- **코멘트(/comment)만 빼기 (기본):** QR 분석 결과처럼 /comment로 넣은 메시지를 요약, 회상 검색, 답변 점검에서 모두 빼요. 예전에는 요약에서만 빠지고 회상 검색에는 들어갔어요.
- **QR·슬래시 명령으로 넣은 메시지 전부 빼기:** /sys(내레이터)와 /sendas로 넣은 메시지까지 모두 빼요. 상태창이나 선택지를 /sys로 띄우는 QR을 쓴다면 이걸 고르세요.
- **빼지 않기:** 예전처럼 /sys 내레이터 메시지도 이야기로 요약해요.

/sys로 이야기 서술을 넣는 경우에는 '코멘트만 빼기'로 두면 서술이 그대로 기억돼요. QR이 /send나 /trigger로 일반 답변을 생성하는 경우는 보통 답변과 구별할 수 없어서 그대로 요약해요.

## v1.9.35 설정 화면 읽기 쉽게, 찾기 쉽게

- **설정 찾기:** 설정 탭 아래에 '설정 찾기' 칸이 생겼어요. "모순", "임베딩", "미리보기"처럼 치면 모든 탭에서 이름이나 설명에 그 말이 들어간 설정만 탭 이름과 함께 모아 보여줘요. 고급 설정 안에 있는 것도 펼쳐서 보여줘요. 지우거나 Esc, 탭을 누르면 원래대로 돌아가요.
- **묶음 제목:** 탭마다 관련 설정끼리 묶고 제목을 달았어요.
  - 요약: 요약 모델 / 요약 방식 / 함께 챙길 것
  - 자동: 자동 압축 / 답변 점검 / 실시간 갱신 / 메시지를 지울 때
  - 회상: 회상 / 검색 방식 / 임베딩
  - 기억 크기: 기억 크기 / 백업
- **탭 이름:** '용량'은 '기억 크기'로, '주입'은 '넣는 위치'로 바꿨어요.
- **고급 설정 정리:** 자동 탭에 '고급 설정'이 두 번 나오던 것을 없앴어요. '검사에 보여줄 최근 대화'와 '압축 알림 기준'은 해당 묶음 안에 바로 보여요.
- **글자:** 설정 이름과 설명 글자를 조금 키우고 줄 간격을 넓혔어요.
- '저장 전에 미리보기' 설명에 자동 압축은 미리보기 없이 바로 저장한다는 내용을 넣었어요.

## v1.9.34 답변을 지우면 실시간 갱신도 되돌리기

'현재 상태 실시간 갱신'을 켜 두면 답변마다 기록부(장소, 시간, 물건, 약속 등)가 바뀌는데, 그 답변을 지워도 바뀐 기록부는 그대로 남았어요.

- **지우면 되돌림:** 실시간 갱신을 한 답변을 지우면, 그 답변 때문에 바뀐 기록부 항목과 지금 상황(시간·장소·함께 있는 인물)을 바뀌기 전으로 돌려요. 그 답변으로 새로 생긴 항목은 빠져요.
- **스와이프:** 다른 답변으로 넘기면 이전 답변의 갱신을 되돌리고, 새 답변 기준으로 다시 갱신해요. 원래 답변으로 다시 넘어오면 그 갱신을 다시 적용해요.
- **나중 변경은 지킴:** 지운 답변 뒤에 같은 항목이 또 바뀌었으면 그 나중 내용은 그대로 둬요.
- **설정:** 설정 → 자동의 '답변을 지우면 그 갱신도 되돌리기'(기본 켜짐)로 끌 수 있어요.

이 버전 이후에 실시간 갱신된 내용부터 되돌릴 수 있어요. 그 전에 바뀐 기록부는 기억장에서 직접 고쳐 주세요.

## v1.9.33 봇 테스터와 함께 쓰기

봇 테스터(3.3.0), 책 먹는 여우(1.15.0)와 같이 켜서 확인했어요. 셋 다 정상으로 켜지고, 저장 칸·명령어·화면 ID·메시지 버튼이 겹치지 않아요.

- 봇 테스터가 자동 테스트를 돌리는 동안에는 코끼리가 답변 점검, 실시간 상태 갱신, 자동 압축, '이어가기' 제안을 쉬어요. 테스트 턴 사이에 요청이 끼어들거나, 이전 채팅 기억이 테스트용 새 채팅에 섞여 봇 평가가 달라지는 일을 막아요. 테스트가 끝나면 바로 다시 켜져요.

## v1.9.32 로컬 임베딩 때문에 실리태번이 꺼지던 문제

임베딩 소스가 'ST 설정 따르기'이면, ST 벡터 저장소를 한 번도 켜지 않은 사람도 ST 기본값인 로컬 임베딩(transformers.js, jina-embeddings)을 쓰게 됐어요. 이 모델은 실리태번 서버 안에서 불러오는데, 휴대폰(Termux)이나 메모리가 작은 기기에서는 "Initializing transformers.js pipeline…" 뒤에 서버가 통째로 꺼질 수 있었어요. 자동 색인이 켜져 있으면 채팅을 열자마자 이렇게 됐어요.

- **안 고른 로컬 임베딩은 쓰지 않아요:** 임베딩 소스를 따로 고르지 않았고 ST 벡터 저장소도 켜지 않았으면 로컬 임베딩을 부르지 않아요. 회상은 키워드 검색으로 계속 돼요.
- **휴대폰은 한 번 확인:** 휴대폰에서 로컬 임베딩을 쓰려면 회상 탭의 임베딩 테스트에서 한 번 확인을 받아요.
- **꺼졌으면 다시 안 부르기:** 로컬 임베딩을 불러오는 도중 실리태번이 꺼지면, 다음에 열 때 알아채고 로컬 임베딩을 쉬어요. 다시 꺼지는 일이 반복되지 않아요. 임베딩 소스를 바꾸거나 임베딩 테스트가 성공하면 다시 켜져요.
- **작동 상태:** 의미 검색을 쉬고 있으면 작동 상태의 '색인' 줄에 이유가 보여요.

의미 검색을 쓰고 싶으면 설정 → 회상의 임베딩 소스를 Google AI Studio(gemini-embedding-001) 같은 API로 고르는 걸 추천해요. 휴대폰에서도 서버에 부담이 없어요.

## v1.9.31 답변 점검: 놓치는 경고 줄이기와 걸러진 경고 보기

1.9.26에서 근거 문장이 원문에 없으면 경고를 바로 버리게 했는데, 모델이 근거를 빼먹거나 조금 다르게 옮겨 적으면 진짜 모순도 버려질 수 있었어요.

- **바로 버리지 않기:** 근거 문장을 원문에서 그대로 못 찾은 경고도 '한 번 더 확인'으로 보내요. 재확인 모델에게 "근거가 원문과 그대로 맞지 않으니 직접 확인하고, 분명한 모순일 때만 남겨라"라고 따로 알려요. 근거가 맞는 경고는 재확인이 아무 말도 안 하면 그대로 남고, 근거가 안 맞는 경고는 재확인이 '남긴다'고 해야 남아요.
- **재확인 실패:** 재확인 응답을 읽지 못하면 아무것도 걸러내지 않고 다 보여줘요.
- **재확인 꺼짐:** '한 번 더 확인'을 꺼 두면 근거가 안 맞는 경고도 보여주고, "근거 문장을 원문에서 그대로 찾지 못했어요"라고 표시해요.
- **활동 기록:** 점검마다 "찾은 경고 3개 → 근거 확인 안 됨 1개 · 재확인에서 1개 걸러짐 → 최종 1개"처럼 몇 개를 찾아서 몇 개를 걸렀는지 남겨요.
- **걸러진 경고 보기:** ⚠ 창 아래 '걸러진 경고 N개 보기'에서 걸러진 경고와 걸러진 이유를 볼 수 있어요. 경고가 전부 걸러진 답변에는 흐린 ⓘ 표시가 붙어서, 눌러 보면 무엇을 걸렀는지 확인할 수 있어요.

## v1.9.28 스마트폰 메신저 3.5 프리셋·확장과 함께 쓰기

스마트폰 메신저 3.5 프리셋과 그 보조 확장('스마트폰 메신저')을 쓰는 채팅에 맞췄어요.

- **대화 방식 자동 감지:** 스마트폰 메신저 확장이 이 채팅에 기록을 남겼으면 바로 메신저로 봐요. 서사 모드로 전환한 적이 있으면 '섞임'으로 봐요.
- **메시지마다 모드 표시:** 확장이 기록한 메신저/서사 전환 시점을 읽어서, 요약 모델에게 줄마다 톡인지 대면 장면인지 알려 줘요. 시간 표시를 끈 설정이어도 구분돼요.
- **속마음:** `<messenger_thinking>`은 '보내지 않은 속마음'으로 넘겨요. 요약과 점검이 속마음을 실제로 한 말처럼 다루거나, 상대가 속마음을 모르는 걸 모순으로 경고하지 않아요.
- **시간 표시:** `chat-timestamp` 같은 시간 칸은 긴 스타일 코드 대신 `[23:41]`로 줄여서 넘겨요.
- **폰 화면:** 코드 블록 안의 전체 HTML 화면(통화, 선물, 지도 등)은 스타일·스크립트를 빼고 `[phone screen: 제목] 보이는 글` 한 줄(300자까지)로 줄여요. 다른 코드 블록은 그대로 둬요.
- **읽씹 연출:** '답장하지 않았다' 표시와 그 뒤 3인칭 장면은 그 인물 쪽의 사정이라 상대는 모른다고 알려 줘요.
- 대사 샘플을 고를 때 이름 뒤 모드 표시나 ★가 붙은 줄도 같은 인물의 줄로 알아봐요.

메시지 원문(mes)은 건드리지 않아서 스마트폰 메신저 확장의 모드 기록, 번역 연결 스크립트와 부딪치지 않아요.

## v1.9.27 톡·문자·전화 채팅 지원

메신저 형태(카톡, 문자, DM)나 전화로 진행하는 채팅도 요약과 검사가 그에 맞게 돌아가요.

- **대화 방식** (기억장 → 작품 설정 → 세계와 언어): 자동 감지 / 대면 롤플 / 메신저·문자(톡) / 전화·통화 / 섞임 중에서 골라요. 기본은 자동 감지이고, 최근 메시지의 시간 표시([오후 3:12]), 톡 관련 말(읽음, 답장, 이모티콘…), 톡 모양 HTML, 전화 관련 말, 메시지 길이를 보고 알아봐요. 지금 무엇으로 보고 있는지 옆에 보여 줘요.
- **요약:** 톡이면 누가 누구에게 언제 무엇을 보냈는지, 시간 표시, 답 안 한 메시지, 읽씹, 보낸 사진·이모티콘, 부재중 전화를 남겨요. 메시지에 없는 신체 접촉이나 같은 장소를 지어내지 않고, 각자 있는 곳은 자기가 말한 곳으로 적어요. ㅋㅋ, ㅇㅇ, ㅠㅠ 같은 표현은 말투로 남겨요. 전화면 누가 걸었는지, 어떻게 끊겼는지, 들린 소리를 남겨요.
- **답변 점검:** 톡·전화에서는 상대가 볼 수 없는 몸짓·옷차림 같은 걸로 경고하지 않아요. 대신 시간이 거꾸로 가는 것, 메시지로 들은 적 없는 걸 아는 것, 방금 말한 위치·행동과 어긋나는 것, 누가 보낸 메시지인지 헷갈리는 것을 봐요.
- **톡 모양 HTML:** 말풍선마다 줄을 나누고, 태그에 들어 있던 보낸 사람·시간(예: data-name, data-time)과 이모티콘·사진 설명(alt)을 살려서 요약에 넘겨요. 예전에는 태그를 지우면서 글이 한 줄로 붙고 누가 보낸 건지 사라졌어요.
- **묶음 크기:** 톡은 메시지가 짧아서 한 번에 최대 3배(150개까지) 묶어 요약해요. 토큰 한도는 그대로라 요청 수만 줄어요.

HTML이 들어 있는 메시지는 글을 읽어 오는 방식이 바뀌어서, 다음 색인 때 그 메시지들만 다시 색인해요.

## v1.9.26 답변 점검이 최근 대화를 기준으로

최근 원본을 20개쯤 남겨 두면, 그 20개 안에서 바뀐 내용(장소 이동, 바꿔 든 물건, 나은 상처 등)을 점검이 보지 못했어요. 바로 앞 12개만 보고 나머지는 그보다 오래된 요약과 비교해서, 이미 이야기 속에서 바뀐 걸 모순이라고 잘못 경고했어요.

- **최근 원본 전부 보기:** 아직 요약하지 않은 최근 원본을 전부 점검 모델에게 보여줘요. 기본 12,000토큰까지예요(설정 → 자동 → 고급의 '검사에 보여줄 최근 대화'). 다 못 넣으면 빠진 구간이 있다고 알려서, 그 구간 때문에 바뀌었을 수 있는 건 경고하지 않게 해요.
- **최신 정보 우선:** 최근 대화가 요약보다 새것이라고 분명히 알려요. 요약에는 몇 번 메시지까지의 내용인지 붙여요. 경고하기 전에 최근 대화 전체에서 그 변화를 설명하는 내용이 있는지 먼저 확인하게 해요. 애매하면 경고하지 않아요.
- **근거 확인:** 경고마다 답변의 어느 부분이 무엇과 어긋나는지, 근거가 되는 원문 문장과 출처(메시지 번호, 기억, 캐해)를 받아요. 근거 문장이 실제로 보여준 내용에 없으면 지어낸 경고로 보고 버려요. 경고 창에서 근거도 같이 보여 줘요.
- **한 번 더 확인 (기본 켜짐):** 모순을 찾았을 때만, 그 경고가 최근 대화로 이미 바뀐 내용이 아닌지 한 번 더 따져서 확실한 것만 남겨요. 모순이 없으면 추가 호출이 없어요.
- 모순 검사 기준의 기본 문장도 '최신 사실 기준'으로 다듬었어요. 직접 고친 기준이 있으면 그대로 두고, 위 판단 규칙은 항상 함께 들어가요.

## v1.9.25 기억을 지울 때 숨긴 원본을 그대로 둘지 고르기

다시 압축하려고 기억을 지우면, 요약하면서 숨겼던 원본 메시지가 전부 다시 보이게 됐어요. 긴 채팅에서는 다음 답변부터 수천 개의 원본이 한꺼번에 AI에게 가서 느려지거나 컨텍스트가 넘쳤어요.

- **기억 초기화**에서 '초기화 · 원본 다시 보이기'와 '초기화 · 숨긴 채로 두기' 중에 고를 수 있어요.
- 숨긴 채로 두면 메시지는 AI에게 계속 안 보이고, 압축(전체 압축)을 누르면 그 메시지들을 처음부터 다시 요약해요. 다시 압축하기 전까지는 AI가 지난 내용을 모르니, 초기화한 뒤 바로 압축하는 걸 권해요.
- 기억장에서 기억을 골라 지울 때도 '지운 기억의 원본'을 '숨긴 채로 두기'나 '다시 보이기'로 고를 수 있어요. 가장 최근 기억을 지우면 어느 쪽이든 그 구간을 다시 압축할 수 있어요.
- /hide나 다른 확장이 숨긴 메시지는 이 선택과 상관없이 건드리지 않아요.

## v1.9.24 한 캐릭터가 '깡'과 'Kkang'으로 두 번 생기던 문제

요약을 영어로 하면 모델이 한국어 이름을 로마자로 바꿔 쓰는 일이 있어서("깡" → "Kkang"), 캐릭터 탭에 같은 인물이 두 칸으로 생겼어요. 말투와 대사 샘플도 두 칸에 나뉘어 쌓였고요.

- 한글 이름과 로마자 이름은 같은 인물인지 맞춰 봐요. Kkang·Ggang·Kang, Jeongu·Jungwoo처럼 로마자 표기가 달라도 같은 인물로 봐요. 같은 글자 체계끼리(한글끼리, 영어끼리)는 이름이 정확히 같을 때만 합쳐요.
- 이미 두 칸으로 나뉜 캐릭터는 채팅을 열 때 자동으로 한 칸으로 합쳐요. 이름은 채팅에서 실제로 쓰는 쪽을 남기고, 다른 이름은 '다른 이름'으로 보여 줘요. 핵심 캐해는 더 긴 쪽, 대사 샘플과 이야기 속 변화는 양쪽을 모두 모아요.
- 요약할 때와 캐릭터 카드에서 정리할 때 이름을 원래 표기 그대로 쓰라고 모델에게 알려요.

- 1.9.20에서 타임라인이 막히지 않게 하면서, 예산을 넘으면 ★ 에피소드도 '지금까지의 이야기'로 합쳐질 수 있었어요. 이제 ★ 에피소드는 고정한 것처럼 건너뛰고 그대로 남겨요.

## v1.9.22 Vertex AI "Publisher model ... was not found"

최신 Gemini 모델 중에는 Vertex AI의 global 지역에서만 제공되는 것이 있어요. 연결 프로필에 지역이 비어 있으면 ST가 us-central1으로 보내서, 채팅은 되는데 요약만 "Publisher model ... was not found or your project does not have access to it" (404)로 실패했어요.

- 이 오류가 나면 API 연결 화면의 지역, global, us-central1 순서로 다른 지역에 한 번씩 다시 보내요.
- 되는 지역을 찾으면 그 프로필은 다음부터 바로 그 지역으로 보내고, 알림으로 알려 줘요.
- 어느 지역에서도 안 되면 지역을 바꾸거나 그 지역에 있는 모델로 프로필을 다시 저장하라고 안내해요.

## v1.9.21 Vertex AI "Service Account JSON is missing" 오류

연결 프로필에는 저장할 때 쓰던 인증 정보(Express API 키 또는 서비스 계정 JSON)의 ID가 같이 저장돼요. 그런데 요약 요청을 보낼 때 인증 방식은 지금 API 연결 화면의 설정을 따라가서, 둘이 다르면 실패했어요. 예를 들어 Express 키로 저장한 프로필을 쓰는데 지금 연결이 서비스 계정 방식이면, ST가 그 키 ID로 서비스 계정을 찾다가 "Vertex AI Service Account JSON is missing."을 띄웠어요.

- 프로필에 저장된 인증 정보가 어떤 종류인지 확인하고, 그에 맞는 방식(Express 또는 서비스 계정)으로 보내요.
- 프로필의 인증 정보가 지워졌거나 다시 올려서 ID가 바뀌었으면, 지금 활성화된 키나 서비스 계정을 대신 써요.
- 저장된 쪽이 한 종류뿐이면(예: 서비스 계정만 있고 API 키는 없음) 그쪽 방식으로 맞춰요.
- 그래도 ST가 이유 없이 400으로 거절하면, 지금 채팅에 쓰는 인증 정보로 한 번 더 보내요.

인증 정보 값은 읽지 않아요. ST가 가려서 주는 ID와 이름만 확인해요.

## v1.9.20 타임라인이 줄지 않고 멈추던 문제

'지금까지의 이야기'로 합치는 단계는 타임라인 맨 앞이 챕터일 때만 동작했어요. 맨 앞에 챕터로 묶이지 못한 오래된 에피소드 하나가 남아 있거나 고정한 항목이 있으면, 그 뒤 챕터들을 하나도 합치지 못하고 멈췄어요. 그러면 타임라인이 그대로 남아 14k 근처에서 더 줄지 않았어요.

- 예산을 넘었을 때는 맨 앞에 남은 에피소드도 이야기로 합치고, 고정한 항목은 건너뛰고 그 뒤를 합쳐요. 고정한 항목은 타임라인에 그대로 남아요.
- 가장 최근 장면들은 여전히 합치지 않아요.
- 모델이 한 번 거부하거나 형식을 틀린 단계는 같은 정리 안에서 한 번 더 시도해요. 이전에는 한 번 실패하면 그 정리가 끝날 때까지 다시 시도하지 않았어요.
- 정리 후에도 예산을 넘으면, 모델이 거부한 단계가 있었는지도 알림에 함께 보여 줘요.

여러 가지 기억 상태를 무작위로 만들어 시험했어요. 예산을 넘은 262개 상태 중 정리 뒤에도 넘친 경우가 24%에서 2%로 줄었어요. 남은 경우는 모델이 이야기 정리를 연달아 거부한 경우예요.

## v1.9.19 각 부분이 '자기 몫'에 맞아도 전체가 넘치던 문제

이야기·기록부·캐릭터에 각각 정해진 몫(이야기 30%, 기록부 40%, 캐릭터 20%)이 있었는데, 여기에 타임라인까지 더하면 예산보다 컸어요. 그래서 모든 부분이 자기 몫 안이라 더 줄일 게 없다고 판단하고, 전체는 예산을 넘긴 채로 멈췄어요.

- 예산을 넘친 만큼을 이야기·타임라인·기록부·캐릭터에 크기 비율대로 나눠서 줄여요. 각 부분에는 최소한 남길 양이 있어요.
- 그래도 넘치면 마지막 단계로 아래를 차례로 해요.
  - 가장 최근 장면 하나를 뺀 최근 장면들도 한 번 가볍게 줄여요(원문은 보관함에 남아요).
  - 이미 한 번 줄인 긴 기록을 한 번 더 짧게 써요.
  - 가장 최근 메시지에서 바뀌지 않은 기록은 보관함으로 옮겨요.
- 캐릭터 설명도 두 단계로 줄여요. 두 번째 단계에서는 지금 장면 인물도 말투 예시 2개와 최근 변화만 남겨요.
- 고정한 기억, 꼭 기억할 것, ★ 장면, 가장 최근 장면은 여전히 건드리지 않아요.

## v1.9.18 '지금까지의 이야기'가 커져도 줄어들게

'지금까지의 이야기'는 1,500단어 안으로 쓰라고만 요청하고 결과 길이를 확인하지 않았어요. 모델이 이전 이야기를 그대로 베끼고 새 챕터를 덧붙이면 이야기 하나가 3만 토큰 넘게 커질 수 있었고, 이걸 다시 줄이는 단계가 없어서 정리를 눌러도 더 줄지 않았어요.

- 이야기가 목표 크기(기억 크기 한도의 30%, 기본 약 3,600토큰)보다 크면 정리 때 자동으로 줄여요.
- 긴 이야기는 여러 조각으로 나눠 앞에서부터 순서대로 줄이고, 한 번에 다 못 줄이면 최대 세 번까지 다시 줄여요.
- 모델이 길이 제한을 무시하면 절반 길이로 한 번 더 요청하고, 더 짧은 쪽만 받아요. 원래보다 길어지는 결과는 버려요.
- 줄이기 전 원래 이야기는 보관함에 남겨서 회상 검색으로 세부 내용을 다시 찾을 수 있어요.
- 모델이 거부해서 실패하면 자동 정리에서는 다시 시도하지 않고, 직접 정리를 누를 때 다시 시도해요.

업데이트 후 정리를 한 번 누르면 돼요. 중요도를 손으로 바꿀 필요는 없어요.

## v1.9.17 정리가 끝까지 줄이게

손으로 중요도를 조절하지 않아도 정리가 예산까지 줄이도록 단계를 더했어요. 예산을 넘으면 아래 순서로 계속 줄여요.

1. 오래되고 덜 중요한 기록부 항목을 보관함으로 옮겨요.
2. 중요도 4인 요약을 한 번 줄여요.
3. 긴 기록부 항목을 모델로 짧게 다시 써요. 이름·숫자·상태·비밀·아는 사람은 남겨요.
4. 오래 안 바뀐 중요도 5 기록을 보관함으로 옮겨요.
5. 장면에 없는 인물의 설명을 짧게 넣어요.
6. 중요도 5 요약도 한 번 줄여요.
7. 마지막으로, 최근에 바뀌지 않은 기록은 지금 장면 인물에 관한 것이라도 보관함으로 옮겨요.

보관함으로 간 기록은 회상 검색으로 필요할 때 다시 꺼내 와요. 고정한 기억, 꼭 기억할 것, ★ 중요 장면, 최근 장면은 끝까지 건드리지 않아요.

## v1.9.16 정리해도 크게 남던 문제

- 정리 중에 모델이 한 단계(예: 지금까지의 이야기로 합치기)를 거부하거나 이상하게 답하면 정리 전체가 멈췄어요. 이제 그 단계만 건너뛰고 나머지 정리를 계속해요.
- 모델이 대부분의 기록에 중요도 5를 매기면 기록부가 줄지 않았어요. 이제 그래도 넘치면 오래(기본 400메시지) 안 바뀐 중요도 5 기록도 보관함으로 옮겨요. 회상 검색으로는 계속 찾아 와요. 고정한 기록과 꼭 기억할 것은 그대로예요.
- 캐릭터가 많으면 캐릭터 설명이 커졌어요. 이제 예산을 넘으면 지금 장면에 없는 인물은 짧게 보여줘요. 저장된 설명은 그대로예요.
- 정리 뒤에도 예산보다 크면, 무엇이 얼마나 남았는지와 왜 안 줄었는지 알려줘요.

## v1.9.15 기억 크기가 예산을 넘던 문제

긴 채팅을 한 번에 요약하면 기억 크기가 예산(기본 12,000)을 훨씬 넘던 문제를 고쳤어요. 정리는 타임라인만 줄이고 기록부에는 한도가 없어서, 인물·사실·물건 기록이 쌓이면 수만 토큰이 됐어요.

- 예산을 넘으면 오래 안 바뀌고 덜 중요한 기록부 항목을 보관함으로 옮겨요. 기록부가 예산의 40% 안에 들어갈 때까지 옮겨요. 보관함으로 간 기록도 회상 검색으로 필요할 때 다시 꺼내 와요.
- 고정한 기록, 꼭 기억할 것, 중요도 5, 최근에 바뀐 기록, 지금 장면에 있는 인물의 인물·관계 기록은 옮기지 않아요.
- 그래도 넘치면 중요도 4인 요약도 한 번 가볍게 줄여요. 중요도 5, 중요 장면(★), 고정한 요약은 줄이지 않아요.
- 패널의 기억 크기 아래에 무엇이 얼마나 차지하는지(이야기·타임라인·기록부·캐릭터·복선) 보여줘요.

이미 커진 기억은 패널의 "정리"를 한 번 누르면 예산에 맞춰 줄어요.

## v1.9.14 캐해 정리 실패 고침

Gemini 같은 모델이 캐해 정리 결과를 JSON 대신 `<character><name>…</name><core>…</core></character>` 같은 태그 모양으로 돌려주면 "해석하지 못했습니다"로 실패하던 문제를 고쳤어요. 이제 태그 모양도 읽고, 그래도 못 읽으면 한 번 더 형식을 짚어서 다시 요청해요. "원본 대사에서 말투 다시 모으기"도 같은 방식으로 읽어요.

## v1.9.13 답변 점검이 멈추던 문제

- 점검 요청이 응답 없이 멈추면 "검사하는 중"이 계속 떠 있고, 그 뒤로는 점검이 아예 안 돌았어요. 이제 2분이 지나면 포기하고 다음 답변부터 다시 점검해요.
- 점검 중에 새 답변이 오면 건너뛰지 않고, 지금 점검이 끝나는 대로 가장 최근 답변을 점검해요.
- 점검할 때 보는 범위를 넓혔어요. 바로 앞 대화를 4개에서 최대 12개(약 3,500토큰)까지 보고, 지금 장면 정보와 최근 요약 2개, 그리고 새 답변과 관련된 예전 장면(회상 검색)도 함께 봐요.
- 모순 검사 기준에 작은 연속성 실수(들고 있는 것, 마시는 것, 입은 것, 어느 손인지, 자리, 시간대)를 넣었어요.

경고 창을 "새로 생성" 없이 닫아도 점검은 꺼지지 않아요.

## v1.9.12 확장이 안 보이던 문제

- 글꼴(Pretendard)을 CSS에서 불러오던 방식을 바꿨어요. 글꼴 서버(jsDelivr)에 못 닿으면 SillyTavern이 확장 전체를 "활성화 실패"로 처리했어요. 이제 글꼴을 못 받아도 확장은 그대로 켜지고, 기본 글꼴로 보여요.
- 설정 패널을 SillyTavern이 시작을 끝낼 때까지 기다리지 않고 바로 붙여요. 다른 확장이나 느린 네트워크 때문에 시작이 늦어지면 패널이 안 보이던 문제를 막았어요.

설치할 때 확장 폴더 바로 안에 manifest.json이 있어야 해요 (예: `data/default-user/extensions/dont-think-of-elephant/manifest.json`). 폴더가 한 번 더 겹치면 SillyTavern이 목록에서 빼 버려요.

## v1.9.11 무거운 채팅에서 렉·튕김 줄임

정규식과 로어북이 많은 시뮬봇(긴 HTML 상태창이 붙는 채팅)에서 요약할 때 렉이 걸리거나 SillyTavern이 튕기던 문제를 줄였어요.

- 요약 한 번에 채팅 파일을 두 번씩 저장하던 것을 한 번으로 줄였어요. 전체 압축 중에는 20초마다, 그리고 끝날 때 저장해요.
- 메시지에서 HTML을 걷어낸 결과를 기억해 두고 다시 쓰고, 검색용 묶음의 계산도 다시 쓰도록 바꿨어요. 답변마다 기억을 찾는 준비가 1,500개 메시지 기준 약 235ms에서 약 7ms로 줄었어요.
- 작동 상태 칸의 숫자를 셀 때 채팅 전체를 다시 읽지 않아요(약 250ms에서 1ms).
- 메시지 속 이미지(base64)와 아주 긴 덩어리는 요약에 넣지 않아요. 닫히지 않은 <style> 태그 때문에 느려지던 것도 막았어요.
- 로어북의 정규식 키를 한 번만 만들고, 항목이 많으면 중간중간 화면이 숨 쉴 틈을 줘요.
- 자동 압축은 답변이 다 그려지고 답변 점검이 끝난 뒤(약 4초 뒤, 생성 중이면 더 기다렸다가) 시작해요.

## v1.9.10 한국어로 보기 고침

영어로 압축한 기억을 "한국어로 보기"로 열면 일부만 한국어로 바뀌고, 특히 긴 에피소드는 영어로 남던 문제를 고쳤어요. 예전에는 20개씩 한꺼번에 번역을 맡겨서, 긴 에피소드가 섞이면 답이 중간에 잘리고 그 묶음 전체가 영어로 남았어요. 실패한 결과가 저장돼서 다시 열어도 영어였고요.

- 긴 요약은 하나씩, 짧은 것은 작은 묶음으로 나눠서 번역해요.
- 묶음에서 빠진 항목은 따로 한 번 더 번역해요. 답이 잘려도 온전히 받은 부분은 살려요.
- 번역에 실패한 부분은 저장하지 않아서, 다시 열면 그 부분만 다시 번역해요. 몇 개가 원문으로 남았는지도 알려줘요.
- 한국어 이름이 섞인 영어 문장도 번역하고, 작중 시간과 안 풀린 복선도 한국어로 보여줘요.

## v1.9.9 Vertex AI 오류 고침

요약 모델로 Vertex AI 연결 프로필을 고르면 "API key is required for Vertex AI Express mode" 오류가 나던 문제를 고쳤어요. 연결 프로필로 보내는 요청에는 Vertex AI 인증 방식(Express 키 / 서비스 계정)이 빠져서, 서비스 계정(Full)을 쓰는 사람도 Express로 처리됐어요. 이제 API 연결 화면에서 고른 인증 방식, 프로젝트 ID, 지역을 함께 보내요.

## v1.9.8 화면 잘림 고침

휴대폰처럼 좁은 화면에서 기억장 일부가 잘리던 문제를 고쳤어요.
- 기억장 탭을 옆으로 밀지 않아도 되게, 좁은 화면에서는 탭 10개를 두 줄로 모두 보여줘요.
- 타임라인 카드의 작중 시간·키워드 칸과 복선의 "어떻게 풀렸나" 칸이 오른쪽으로 삐져나가던 문제를 고쳤어요.
- "더보기" 메뉴가 화면 왼쪽 밖으로 나가던 문제를 고쳤어요.
- 중요도·고정·삭제 버튼 줄이 좁은 카드에서 넘치지 않게 크기를 맞췄어요.
- 복선 종류 칸의 글자가 잘리지 않게 넓혔어요.

320px부터 1440px까지 SillyTavern 기본 스타일을 씌운 상태로 설정 패널, 기억장 모든 탭, 팝업을 점검했어요.

## v1.9.7 401 오류 고침

채팅은 되는데 코끼리 요약만 401(인증 오류)이 뜨던 문제를 고쳤어요. 설정 → 요약 탭에서 "요약 모델"이나 "검열되면 대신 쓸 모델"로 연결 프로필을 골랐을 때 생겨요. 프로필에 예전 API 키가 저장돼 있거나(키를 지우거나 바꾼 경우), 프록시를 프로필에 저장하지 않았거나, Custom 주소의 헤더가 빠진 경우예요.

이제 401이 나면 먼저 지금 선택된 키와 지금 쓰는 프록시로 같은 프로필에 다시 보내요. 그래도 안 되면 그 요청은 지금 채팅에 쓰는 연결로 대신 요약해요. 근본적으로 고치려면 API 연결 화면에서 키·프록시를 맞춘 뒤 Connection Profile의 저장(업데이트) 버튼을 눌러 주세요.

## v1.9.6 새 기능 8가지

- **중요 장면 표시 ★**: 메시지 버튼의 별을 누르면 중요 장면이 돼요. 요약할 때 그 장면을 자세히 남기고 중요도를 4 이상으로 올리며, 정리할 때 줄이지 않고, 회상 검색에서도 먼저 떠올려요. `/lm-star 123`
- **요약 자동 검수**: 설정 → 요약 → "요약 자동 검수". 요약을 원본과 한 번 더 대조해서 지어낸 내용이나 빠진 중요 장면을 찾아요. "틀린 곳만 표시"는 타임라인에 "검토 필요"를 달아 두고, "틀리면 고쳐서 다시 요약"은 지적받은 곳을 반영해 한 번 다시 써요. 이미 만든 요약은 기억장 → 타임라인 → "최근 요약 검수"나 `/lm-verify 5`로 검수해요.
- **복선 추적**: 요약할 때 나중에 회수될 암시·수수께끼·약속을 따로 모아요(기억장 → 복선 탭). 안 풀린 복선은 중요한 것부터 AI에게 "잊지 말 것"으로 전달하고, 이야기에서 풀리면 자동으로 회수됨으로 바뀌어요. 직접 추가·수정도 돼요.
- **관계도**: 기억장 → 기록부 → "관계도 보기" (`/lm-relations`). 기록부의 "A -> B" 관계 항목으로 인물 그림을 그려요. 인물을 누르면 그 사람의 관계만, 선을 누르면 설명을 보여줘요.
- **연표**: 기억장 → 타임라인 → "연표로 보기" (`/lm-chronicle`). 작중 시간으로 묶어서 장면·사건·복선을 날짜별로 보여주고, 메시지 번호를 누르면 그 장면으로 이동해요.
- **두 방식 비교해 보기**: 설정 → 프롬프트 → "두 방식 비교해 보기" (`/lm-compare`). 같은 대화를 두 지시문 방식으로 한 번씩 요약해서 나란히 보여주고, 마음에 드는 쪽을 바로 적용해요. 비교 결과는 기억에 저장하지 않아요.
- **비용 예측**: 전체 압축 전에 API 호출 수와 입력·출력 토큰을 어림해서 보여줘요. `/lm-estimate`로 언제든 확인할 수 있어요.
- **다른 채팅 기억 합치기**: 기억장 → 더보기 → "다른 채팅 기억 합치기" (`/lm-merge`). 같은 캐릭터의 다른 채팅, 이어가기로 저장한 기억, 기억 파일(.json) 중에서 골라 지금 기억에 더해요. 지금 기억은 그대로 두고, 겹치는 기록은 지금 것을 남겨요. 되돌리기로 취소할 수 있어요.

새로 생긴 프롬프트 "복선 추적 기준"과 "요약 검수 기준"도 프롬프트 탭에서 고칠 수 있어요.

## v1.9.5 지시문 방식 고르기

설정 → **프롬프트** 탭 맨 위에서 목적에 맞게 다듬어 둔 지시문 묶음을 골라 적용할 수 있어요. 적용하면 아래 프롬프트 칸이 그 방식으로 바뀌고, 그 뒤에도 칸마다 더 고칠 수 있어요.

| 방식 | 이럴 때 | 함께 바뀌는 설정 |
|---|---|---|
| 기본 (균형) | 처음 설정. 기억과 캐해를 고르게 | - |
| 캐해 최우선 | 캐붕이 걱정될 때. 말투·호칭·행동 방식을 가장 꼼꼼히 남기고 AI에게도 강하게 일러요 | 대사 샘플 4줄 |
| 꼼꼼한 기억 | 숫자·시간·물건 위치·약속 문구까지 최대한. 합칠 때도 덜 줄여요 | 상세도 "상세" |
| 토큰 절약 | 짧은 메모로 압축. 작은 컨텍스트나 비용 절약 | 상세도 "간결", 대사 샘플 1줄 |
| 원작 충실 (2차 창작) | 원작 이름·용어·호칭을 정확히, 원작과 달라진 점을 따로 분명히 | - |
| 감정선 · 관계 중심 | 누가 먼저 다가갔는지, 신뢰와 거리감, 풀리지 않은 감정, 둘만의 호칭 | - |
| 사건 · 추리 · 모험 | 단서, 누가 무엇을 봤는지, 확인된 사실과 추측, 소지품, 못 푼 수수께끼 | - |

- **내 방식으로 저장**: 지금 프롬프트 탭의 지시문을 이름을 붙여 저장해요. 언제든 다시 고를 수 있어요.
- **내보내기 / 가져오기**: 방식을 .json 파일로 주고받아요. 다른 사람과 나눌 수 있어요.
- 지금 쓰는 방식에는 "사용 중" 표시가, 그 뒤 직접 고친 칸이 있으면 "고친 칸 n개"가 붙어요. 칸마다 "원래대로"를 누르면 지금 방식의 문구로 돌아가요.
- 어떤 방식이든 결과 형식은 그대로라 요약이 깨지지 않아요.

## v1.9.4 캐해 복구 도구 (이미 압축한 채팅용)

원래 하던 채팅을 압축했더니 캐릭터 성격이 달라졌다면 기억장 → **캐릭터** 탭에서 고쳐요.

- **캐해 점검**: 핵심 캐해, 말투·호칭, 대사 샘플, 최근 원본 유지 개수, 캐해 검사, 인물 기록 상태를 한눈에 보여주고, 손볼 곳마다 바로 고치는 버튼이 붙어 있어요 (예: "최근 원본 유지 40개로", "캐해 검사 켜기").
- **원본 대사에서 말투 다시 모으기** (`/lm-voice`): 요약하면서 숨겨진 원본 메시지는 지워지지 않고 남아 있어요. 거기서 캐릭터마다 대사를 이야기 전체에 걸쳐 골고루 뽑아, 말투 설명과 대사 샘플을 다시 채워요. 다시 요약하지 않으니 기억은 그대로예요. 원문에 정말 있는 대사만 남기고, 잠근 말투는 건드리지 않아요.
- **인물 기록 정리** (`/lm-tidy-cast`): 기록부의 인물 항목에서 "다정해졌다", "차가워졌다"처럼 장면 하나로 성격을 새로 규정한 표현을 걷어내고, 상태·상황·실제 사건만 남겨요. 적용 전에 바뀌는 내용을 미리 보여주고, 되돌리기로 원래대로 돌릴 수 있어요.
- 두 도구의 지시문도 설정 → 프롬프트 탭에서 고칠 수 있어요.

## v1.9.3 한국어로 보기 · 한국어 질문

- **한국어로 보기** (기억장 위쪽 버튼): 지금까지의 이야기, 등장인물, 타임라인, 기록부, 위키를 한국어로 번역해서 읽기 전용으로 보여줘요. 저장된 기억은 요약 언어 그대로라서, 정리·압축·회상은 계속 요약 언어로 돌아가요. 한 번 번역한 문장은 기억해 두었다가 다시 쓰니까 두 번째부터는 빨라요.
- **한국어로 질문해도 찾아요**: 기억이 영어 같은 다른 언어로 쓰여 있으면, 질문을 그 언어로 번역한 검색어를 하나 더 만들어 함께 찾아요. 답은 늘 한국어로 해요.
- **회상도 언어를 넘어 찾아요**: "돌려 말해도 찾기"를 켜 두면, 채팅 언어와 기억 언어가 다를 때 검색어를 두 언어로 만들어요.

## v1.9.1 기본 프롬프트 직접 수정

설정 → **프롬프트** 탭에서 이 확장이 AI에게 보내는 기본 프롬프트를 전부 고칠 수 있어요. 칸마다 지금 쓰는 프롬프트가 그대로 들어 있고, 고치면 그게 새 기본값이 돼요 (모든 채팅에 적용).

- 고칠 수 있는 프롬프트 14가지 (v1.9.4에서 말투 모으기·인물 기록 정리 추가): 공통 요약 지시문, 기록부 작성 기준, 덜 중요한 기억 줄이기, 에피소드 → 챕터 합치기, 챕터 → 지금까지의 이야기, 모순 검사 기준, 캐해 검사 기준, 캐해 정리 지시문, 위키 정리 지시문, 질문 답변 지시문, 검색어 확장 지시문, 기억 주입 머리말
- 고친 칸에는 "수정됨" 표시가 붙고, 칸마다 "원래대로" 버튼이 있어요. 맨 아래 "프롬프트 전부 원래대로"로 한 번에 되돌릴 수도 있어요.
- 기본 문구와 똑같이 되돌려 적으면 자동으로 "기본값 사용"으로 돌아가서, 나중에 확장이 업데이트되면 새 기본 문구를 받아요.
- `{{user}}`, `{{char}}`, `{{language}}`를 어디서든 쓸 수 있어요. 칸에 따라 `{{sensitive}}`(있는 그대로/순화 규칙), `{{sagaWords}}`, `{{canon}}`, `{{covered}}`도 쓸 수 있어요.
- 결과 형식(`<episode>`, `<ledger>` 등)은 프롬프트 뒤에 자동으로 붙어서, 어떻게 고쳐도 요약 해석이 깨지지 않아요.
- 덧붙이는 문구: 추가 요약 규칙, 시스템 맨 앞 / 요청 내용 앞·뒤 문구, 어시스턴트 첫마디(prefill).
- "실제로 보내는 요약 프롬프트 보기"로 결과를 바로 확인할 수 있어요.

## v1.8.1 검열 대응

- 이 확장은 채팅 프리셋의 프롬프트(메인·탈옥 등)를 쓰지 않고, 늘 자체 요약 프롬프트를 보내요. 연결 프로필에서는 API·모델·키만 가져와요 ("프로필의 샘플링 설정 사용"을 켜면 온도 같은 생성 설정도).
- ST는 Gemini 안전 필터를 이미 전부 꺼서(OFF) 보내요. 그래도 막히는 건 Google이 끌 수 없게 둔 검사라서, 설정으로는 못 끄고 아래처럼 피해 가요.
- **거절문을 기억으로 저장하지 않아요**: "죄송하지만…", "I can't…" 같은 답은 요약으로 저장하지 않고 실패로 처리해요.
- **검열되면 대신 쓸 모델** (설정 → 요약): 막히거나 거절될 때만 고른 프로필로 자동으로 다시 보내요. Gemini를 쓴다면 DeepSeek·GLM 같은 다른 회사 모델을 추천해요. 정리·위키·질문 등 모든 요청에 적용돼요.
- **있는 그대로 요약** (v1.8.2부터 기본): 야하거나 잔인한 장면도 빼거나 순화하지 않고 다른 장면과 같은 수준으로 기록해요. 원하면 설정 → 요약 탭의 "민감한 장면 순화"를 직접 켤 수 있어요 (꺼져 있는 게 기본).
- **거부된 구간은 나눠서 다시 요약**: 한 장면 때문에 구간 전체가 막히면 반씩 나눠 문제 장면만 떼어내요. 끝까지 막힌 작은 부분은 빈칸으로 표시하고 "다시 요약"으로 나중에 다른 모델에 맡길 수 있어요.

## v1.8 캐해 보존

요약 기억은 서술자 말투로 쓰이고, 요약한 원본은 AI에게서 숨겨져요. 그래서 대화가 길어질수록 AI는 캐릭터가 실제로 어떻게 말했는지 볼 수 없게 되고, 장면 하나를 성격 변화로 기록하는 일이 쌓이면 캐붕이 생겨요. v1.8은 이걸 막아요.

- **핵심 캐해 고정** (기억장 → 캐릭터): 첫 압축 때 캐릭터 카드(설명·성격·첫 메시지·예시 대화)와 작품 설정, 로어북을 읽고 성격·가치관·결점·대하는 방식·절대 하지 않을 일과 말투를 정리해요. 요약은 이 칸을 절대 바꾸지 않아요. 직접 고치거나 "캐릭터 카드에서 캐해 정리" 버튼으로 다시 채울 수 있어요 (적어 둔 칸은 건드리지 않아요).
- **실제 대사 샘플**: 압축할 때마다 캐릭터가 실제로 한 대사를 1~2줄씩 모아요. 원문에 정말 있는 문장인지 확인하고, 없으면 버려요. 장면에 있는 인물은 샘플 몇 줄을 AI에게 같이 보여줘서 숨겨진 원본 대신 말투를 붙잡아 줘요. 고정한 샘플은 지워지지 않아요.
- **말투 · 호칭**: 반말/존댓말, 1인칭, 어미, 버릇, 서로 부르는 호칭을 따로 기록해요. 원하면 자동 갱신을 잠글 수 있어요.
- **이야기 속 변화**: 관계가 깊어지는 등 실제로 생긴 변화는 원인과 함께 따로 기록하고, 핵심 성격은 그대로 둔 채 천천히 반영하게 해요.
- **요약 규칙 강화**: 장면 하나로 성격을 다시 쓰지 않고, 어떻게 말하고 행동했는지(퉁명스럽게, 장난스럽게…)를 살려 기록하고, 관계는 근거와 호칭 중심으로 감정을 부풀리지 않게 해요. 챕터·줄거리로 합칠 때도 같은 규칙을 지켜요.
- **현재 상태 리마인더**에 장면 속 인물의 말투를 짧게 넣어서, 긴 대화 끝에서도 말투가 흐려지지 않게 해요.
- **캐해 검사** (설정 → 자동): 모순 검사를 할 때 말투·호칭·성격이 어긋난 답변에 "[캐해]" 경고를 붙여요. 추가 호출은 없어요.
- "이 캐릭터의 기본값으로 저장"을 누르면 캐해도 함께 저장돼서 새 채팅에 자동으로 들어가요. 새 채팅으로 이어가기, 내보내기, 되돌리기에도 포함돼요.
- 끄려면 설정 → 요약 탭의 **캐해 보존**을 끄세요. 장면 속 인물당 대사 샘플 수는 주입 탭에서 정해요.

## v1.7.2 자동 색인 켜기/끄기

- 설정 → 회상 탭의 **자동 색인**, 작동 상태의 "색인" 줄 스위치, `/lm-autoindex on|off`로 켜고 끌 수 있어요.
- 끄면 압축하거나 기억이 바뀌어도 알아서 색인하지 않고, **전체 색인** 버튼을 누를 때만 색인해요. 이미 만든 색인으로 의미 검색은 계속돼요. 임베딩 무료 한도를 아끼고 싶을 때 유용해요.

## v1.7.1 벡터 오류 고침

- **Google AI Studio 모델 자동 교정**: ST 벡터 설정의 기본값 `text-embedding-005`는 Vertex 전용이라 AI Studio에서는 항상 실패했어요. AI Studio에서는 `gemini-embedding-001`로 자동으로 바꿔 보내요 (`text-embedding-004`, `embedding-001`처럼 종료된 모델도 마찬가지).
- **Vertex + gemini-embedding**: 한 번에 한 문장만 받는 모델이라 한 개씩 나눠 보내요.
- **무료 한도 대응**: 실패하면 몇 초 쉬었다가 최대 3번 다시 시도하고, 그래도 안 되면 이미 저장된 만큼은 남겨두고 몇 분 동안 키워드 검색만 쓰다가 자동으로 이어서 색인해요. 그동안 답변이 느려지지 않아요.
- **원인 안내**: 작동 상태와 오류 알림에 어떤 설정을 확인해야 하는지 알려주고, 회상 탭과 작동 상태의 **임베딩 테스트** 버튼으로 바로 확인할 수 있어요.

## v1.7 새 기능

- **숨긴 메시지까지 전부 색인** (설정 → 회상, 기본 켜짐): 요약했는지와 상관없이, `/hide`나 다른 확장이 숨긴 메시지까지 모든 원본 대사를 검색 대상에 넣어요 (최근 원본 유지 개수만큼은 제외). 지금 AI가 그대로 보고 있는 메시지는 회상에서 빼서 토큰을 낭비하지 않아요. 회상 탭의 **전체 색인** 버튼으로 한 번에 색인하고, 진행 상황은 ST 알림창에 표시돼요 (거기서 중지도 가능).
- **작동 상태**: 패널 가운데에서 기억 주입, 회상, 색인, 자동 압축, 답변 점검이 지금 켜져 있는지(초록 점), 꺼져 있는지(빈 점), 오류인지(빨간 점), 마지막으로 무엇을 했는지 바로 보여줘요. 예: "5개 찾아 넣음 (원본 대사 2) · 의미+키워드 · 방금". 자동 압축은 여기서 바로 켜고 끌 수 있어요.
- **AI에게 가는 내용**: 다음 답변 때 프롬프트에 실제로 들어가는 기억, 현재 상태 리마인더, 회상 결과를 위치와 토큰 수와 함께 보여줘요.
- **활동 기록**: 압축, 회상, 색인, 점검, 삭제 반영, 오류를 시간순으로 남겨요.
- **오래 걸리는 작업은 ST 알림창**으로 진행률을 보여줘서 패널을 닫아도 확인하고 멈출 수 있어요.
- **정돈된 화면**: 패널은 [압축][전체 압축] + [기억장 · 묻기 · 정리 · 되돌리기] 두 줄로 줄이고, 설정은 탭마다 자주 쓰는 것만 보이고 나머지는 "고급 설정"에 접어 뒀어요. 탭은 요약 · 자동 · 회상 · 로어북 · 용량 · 주입으로 다시 나눴어요. 기억장 도구는 [백업] + [더보기] 메뉴로 모으고, 카드 입력칸은 평소엔 글처럼 보이다가 누르면 편집되게 바꿨어요. 중요도·고정·삭제 버튼은 한 묶음으로 붙어 다녀요.

## v1.6 새 기능

- **세계와 언어** (기억장 → 작품 설정): 시대, 세계 문화권, 채팅에 쓰는 언어, 이름 표기를 따로 정해요. 예를 들어 일본 만화 2차 창작이면 "세계 문화권: 일본, 채팅 언어: 한국어"로 두면, 인물들은 일본 현대 사회의 호칭·학교·화폐·지명을 쓰면서 대사와 서술은 한국어로 나와요. "시대 · 상황 설명"에는 "2024년 도쿄, 고등학교 2학년 봄"처럼 자유롭게 적어요.
- **로어북 참고** (설정 → 요약 탭): 캐릭터 로어북, 채팅 로어북, 직접 고른 로어북에서 지금 내용과 관련된 항목만 골라 요약, 모순 검사, 위키, 질문 답변에 함께 넘겨요. 이름과 설정이 로어북과 어긋나지 않게 해줘요.
- **질문하기** (기억장 → 질문, 마법봉 메뉴 "코끼리에게 묻기", `/lm-ask`): "레온이랑 처음 만난 게 언제였지?"처럼 물으면, 기억과 로어북을 찾아서 언제(작중 시간과 메시지 번호), 무슨 일이 있었는지 답해요. 답의 #번호를 누르면 그 메시지로 이동해요.
- **위키** (기억장 → 위키, `/lm-wiki`): 기록부와 사건을 바탕으로 인물, 장소, 물건, 집단, 용어를 문서로 정리해요. 검색과 .md, .html 내보내기를 지원해요.
- **대량 삭제**: 타임라인, 기록부, 사건, 위키, 보관함에서 체크박스로 여러 개를 골라 한 번에 지워요. Shift를 누른 채 누르면 사이를 한꺼번에 선택하고, 휴대폰에서는 "범위 선택"을 켜고 처음과 끝을 차례로 누르면 돼요. 타임라인에서 "원본 다시 보이기"를 켜고 지우면, 그 기억의 메시지가 다시 AI에게 보여요.
- **새 디자인**: Pretendard 글꼴, 직접 그린 선 아이콘, 아이보리와 잉크색에 브론즈 포인트를 쓴 차분한 테마로 바꿨어요. 어두운 ST 테마에서는 차콜과 골드 톤으로 자동으로 바뀌어요.
- **모바일**: 입력할 때 화면이 확대되지 않게 했고, 버튼을 더 크게, 도구 줄과 탭은 옆으로 넘겨볼 수 있게, 입력칸은 한 줄로 쌓이게 했어요.

## v1.5 새 기능

### 기억력
- **누가 무엇을 아는지**: 비밀마다 "아는 인물"을 따로 기록해요. AI에게 "이 비밀은 이 인물들만 안다"고 알려줘서 모르는 걸 아는 캐릭터를 막아요. 기억장 기록부에서 직접 고칠 수도 있어요.
- **작중 날짜와 기한**: 에피소드와 사건에 작중 시간을, 진행 중인 약속에 기한을 기록해요.
- **모순 검사** (검사 탭): AI 답변이 끝나면 요약 모델이 기억과 다른 부분을 찾아 메시지 이름 옆에 ⚠ 표시를 해요. 눌러서 이유를 보고 새로 생성하거나 경고를 지울 수 있어요.
- **현재 상태 실시간 갱신** (검사 탭): 압축 전에도 매 답변마다 시간·장소·함께 있는 인물·약속을 갱신해요. 모순 검사와 같이 켜도 호출은 1번이에요.
- **돌려 말해도 찾기** (회상 탭): "그때 그 일" 같은 애매한 말을 구체적인 검색어로 바꿔서 찾아요.
- **기억에 새기기**: 메시지의 ⋯ 메뉴에 있는 압정 버튼으로 그 장면을 "꼭 기억할 것"에 고정해요. `/lm-remember 내용`으로도 돼요.

### 메시지를 지우거나 고치면
- 요약된 메시지에는 어느 기억에 들어갔는지 표시가 남아요. 그래서 중간 메시지를 지워서 번호가 밀려도 정확히 따라가요.
- 한 기억의 메시지를 **모두 지우면 그 기억과 사건도 자동으로 지워요** (범위 탭에서 끌 수 있어요).
- 일부만 지우거나 고치면 기억장에 **다시 요약** 버튼이 생겨요. 누르면 그 구간만 다시 요약해요.

### 편의
- **자동 압축 켜기/끄기**: 패널의 스위치, 마법봉 메뉴, `/lm-auto on|off`. 미요약이 기준만큼 쌓이면 답변 후 한 구간씩 자동으로 압축해요.
- **저장 전 미리보기** (요약 탭): 압축 결과를 보고 고치거나 다시 요약해요.
- **새 채팅으로 이어가기**: 기억장에서 "새 채팅으로 이어가기"를 누르고 같은 캐릭터로 새 채팅을 열면 이어받을지 물어봐요. "이어받기"로 직접 가져올 수도 있어요.
- **내보내기**: 기억 백업(.json), 읽기용 문서(.md), ST 로어북(월드인포 .json), 확장 설정(.json). 가져오기는 기억 파일과 설정 파일 둘 다 돼요.
- **자동 백업**: 압축을 정해진 횟수만큼 할 때마다 브라우저에 백업해요. 기억장의 백업 메뉴에서 되돌리거나 내려받을 수 있어요.
- **주입 프리셋** (주입 탭): 안정형 · 최근 강조형 · 유저 메시지형 · 토큰 절약형 중 골라 한 번에 적용해요.
- 메시지 메뉴의 책 버튼을 누르면 그 메시지가 들어간 기억으로 바로 이동해요.

> 모순 검사, 실시간 갱신, 돌려 말해도 찾기, 자동 압축은 요약 모델을 추가로 호출해요. 요약 모델 프로필을 따로 지정해 두면 대화와 겹치지 않고 비용도 조절하기 쉬워요.

## 설치

1. ST 상단 **확장(Extensions)** 메뉴 → **Install extension** 에 이 확장의 GitHub 주소를 넣거나,
2. 폴더째로 `SillyTavern/data/<사용자>/extensions/dont-think-of-elephant/` 에 복사합니다. (`manifest.json`이 폴더 바로 안에 있어야 해요)
3. ST를 새로고침하고 확장 패널에서 **🐘 코끼리를 생각하지마**을 펼칩니다.

## 처음 쓰는 순서

1. **연결 프로필 만들기 (선택)**: ST의 Connection Manager에서 요약용 프로필(예: 싸고 컨텍스트 큰 모델)을 저장하고, 확장 패널 설정 → 요약 탭의 "요약 모델"에서 고릅니다. 비워두면 지금 쓰는 API로 요약해요.
2. **요약 언어 고르기**: 채팅 언어 / English / 한국어 / 日本語 / 中文. English가 토큰이 가장 적게 듭니다.
3. **2차 창작이라면**: 패널의 **기억장** → "작품 · 캐릭터 설정"에서 작품 유형, 원작 제목, 캐릭터 소개, AU 배경을 적고 저장하세요. "이 캐릭터 기본값으로 저장"을 누르면 그 캐릭터로 새 채팅을 열 때마다 자동으로 불러옵니다.
4. **이미 긴 채팅이면 "전체 압축"**: 남은 메시지를 여러 번에 나눠 처음부터 순서대로 요약합니다. 1000턴 채팅이면 수십 번 API를 호출하니, 구간 크기를 모델 컨텍스트에 맞게 키우면 호출 횟수가 줄어요.
5. 이후로는 대화가 쌓일 때마다 **압축** 버튼(또는 마법봉 메뉴의 "기억 압축")을 누르면 됩니다. 미요약이 많이 쌓이면 알림이 떠요.

## 주요 설정 (기본값)

- 최근 원본 유지 20개 · 한 구간 최대 40개 / 24,000토큰 · 요약 응답 최대 4,096토큰
- 기억 예산 12,000토큰 · 에피소드 12개 넘으면 5개씩 챕터로 · 챕터 8개 넘으면 줄거리로
- 회상: 최대 6개 · 1,500토큰 · 최근 메시지 4개로 검색 · 가중치 관련도 70 / 중요도 20 / 최근성 10
- 모든 숫자 상한을 크게 열어 두었습니다 (예: 구간 최대 200만 토큰, 기억 예산 200만 토큰). 요약 모델의 컨텍스트 한도 안에서 조절하세요.

## 알아둘 점

- 기억은 **채팅마다** 따로 저장됩니다 (채팅 파일 메타데이터). 채팅을 분기하면 기억도 같이 복사돼요.
- 요약한 원본은 삭제되지 않습니다. AI에게만 숨겨지고(채팅창에선 흐리게 표시), 되돌리기나 초기화로 언제든 복구됩니다.
- 요약된 구간 **안쪽** 메시지를 나중에 지우면 메시지 번호가 밀려 범위 표시가 어긋날 수 있어요. 기억 내용 자체에는 영향이 없습니다.
- 기억 예산은 목표치입니다. 고정 항목과 최신 에피소드는 줄이지 않기 때문에 예산보다 조금 클 수 있어요.
- 작품 설정에 적은 내용과 추가 요약 규칙은 그대로 AI에게 전달됩니다.

## 보안

이 확장은 브라우저에서 자바스크립트로 실행되며 채팅 기록과 설정에 접근할 수 있습니다. 요약할 대화는 선택한 연결 프로필(또는 현재 API)로만, 검색용 텍스트는 ST 서버의 벡터 저장소(그리고 거기서 고른 임베딩 서비스)로만 보내고, 다른 곳으로는 전송하지 않습니다. API 키는 다루지 않아요(ST 연결 프로필이 관리). 다른 사람이 수정한 버전을 받을 때는 코드를 확인하세요.

## 이전 버전(Long Memory)에서 옮겨올 때

기존 `st-long-memory` 폴더를 지우고 이 폴더를 넣으면 됩니다. 저장 방식은 그대로라서 **채팅별 기억과 설정이 모두 이어집니다.** 두 폴더를 같이 두면 확장이 두 번 실행되니 꼭 하나만 남겨주세요.
